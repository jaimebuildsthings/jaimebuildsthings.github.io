This is the first post on jaimebuildsthings.dev. Each post gets the next revision letter, starting with A.

## Why it looks like this

The site is styled like a technical drawing: a sheet border, a grid, a title block in the footer, and a diagram of how a project goes from idea to shipped.

There’s a dark theme (blueprint) and a light one (whiteprint). It follows your system setting, and the button in the header switches it.

## What it’s built with

- **Astro** for static pages, with posts written in Markdown
- **GitHub Pages** for hosting, deployed by a GitHub Actions workflow on every push to `main`
- **Cloudflare** for DNS
- **Big Shoulders Display**, **IBM Plex Sans** and **IBM Plex Mono** for type

## What’s next

I’m working on two hardware projects for autocross: [corner-scales](https://github.com/jaimebuildsthings/corner-scales), wireless corner-weight scales in embedded Rust, and [pit-pyro](https://github.com/jaimebuildsthings/pit-pyro), a handheld tire pyrometer. I’ll post build notes on both here, plus [Stringline](https://stringline.ing) updates and the occasional work lesson.

There’s an [RSS feed](/rss.xml) if you want to follow along.
